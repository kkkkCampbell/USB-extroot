# USB-extroot (v0.1.15)

Перенос overlay OpenWrt на USB-накопитель (extroot) с поддержкой отката.  
Увеличивает объём доступной ROM до объёма USB-накопителя.  
Однокликовое решение. :)

## Запуск скрипта  
  
ПЕРЕД ПЕРЕНОСОМ СБРОС РОУТЕРА ДО НАСТРОЕК ПО УМОЛЧАНИЮ НЕ ТРЕБУЕТСЯ!  
  
Скопировать и вставить в терминал ссылку.  
Нажать Ввод.

    sh <(wget -qO- https://raw.githubusercontent.com/kkkkCampbell/USB-extroot/refs/heads/main/usb-extroot.sh)

Меню:

    1) форматировать и перенести overlay на USB-носитель
    2) перенести без форматирования (удалить overlay-структуру)
    3) восстановить загрузку с внутренней памяти роутера
    4) Выбор загрузочного устройства, клонирование накопителя
    0) выход

Пункт 1 — флешка форматируется в ext4, все данные уничтожаются, overlay разворачивается на неё.  
После ребута система грузится с USB.  

Пункт 2 — используется существующая ФС ext4.  
Удаляется только overlay-структура (upper/, work/, .fs_state), затем распаковывается overlay.  
Остальные файлы, ранее размещённые на носителе, не удаляются и не изменяются. 

Пункт 3 — extroot отключается, overlay возвращается на NAND роутера.  
Флешка становится обычным накопителем.  

Пункт 4 — работа с несколькими накопителями (USB-hub), клонирование накопителей, смена загрузочного накопителя.

Пункт 0 — выход без изменений.  

## Требования

- OpenWrt.  
- USB-накопитель (ext4, или чистый/с любой фс — п.1 отформатирует).  
- Место в /tmp под бэкап overlay.  

## Особенности

- Бэкап overlay — в /tmp (tmpfs, RAM), флеш-память не занимается.  
- Пакеты (block-mount, kmod-fs-ext4, e2fsprogs, GNU tar) ставятся автоматически через apk/opkg.  
- При блокировках репозиториев делается попытка временно обойти блокировки (без гарантий).  
- Двойной ребут через rc.local для корректного применения extroot. Производится однократно.
- Система работает и с флешкой, и без неё (откат на NAND).  
- Повторный перенос: с одной флешки на другую, без перепрошивки. (временно исключён)
